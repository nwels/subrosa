# Prototype Web

## What is this project about?

This is a prototype web project designed as a social-style confession platform with Firebase-backed logging and interactive frontend animation. It blends a posts/comments feed experience with a styled user interface and a structured, animated presentation.

## What I aim for

- Build a logging system for Firebase data to store confessions, likes, and comments.
- Follow a social media "Thread" concept with feed items, detail views, and interactions.
- Add CSS animations and visual polish.
- Support anonymous posting while preserving a sense of flow and privacy.

## Project structure

- `index.html` — entry page with intro animation, audio background, and navigation to the confession experience
- `main.html` — main app interface for confession feed, comments, and post interactions
- `logo2.png` / `logo.png` — project branding images
- `background.mp3` — background audio for the intro

## Notes

This prototype is focused on demonstrating a concept rather than a polished production app. It is meant to show how Firebase data can be logged and displayed through a social-thread-inspired UI, while using CSS animation and structure.
